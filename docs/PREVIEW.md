# 下载与使用 Rhine Music Preview

[← 首页](../README.md) · [文档导航](README.md) · [反馈问题](https://github.com/YingYveltal/Rhine-Music/issues)

当前公开试用版为 **v0.1.0-preview.2**，适用 **Apple Silicon Mac（M 系列芯片）、macOS 14 或更新版本**。暂无 Intel Mac 或 Windows 安装包。Preview 仍在迭代，其他设备与账号的兼容性需要试用反馈。

## 下载与安装

[**下载 macOS arm64 ZIP（约 41 MB）**](https://github.com/YingYveltal/Rhine-Music/releases/download/v0.1.0-preview.2/Rhine-Music-Preview-v0.1.0-preview.2-macOS-arm64.zip) · [Release 与校验文件](https://github.com/YingYveltal/Rhine-Music/releases/tag/v0.1.0-preview.2)

1. 下载 `Rhine-Music-Preview-v0.1.0-preview.2-macOS-arm64.zip`，完整解压。
2. 将 **Rhine Music Preview.app** 拖到“应用程序”，再双击打开。运行安装包不需要 Node.js、Rust 或命令行。
3. 初次没有曲库时，可选“先查看演示封面”体验浏览，再打开“音乐库”连接自己的音乐。演示模式只有抽象封面，没有歌曲。

Release 页自动提供的 **Source code** 压缩包供开发者使用，不是 `.app` 安装包。

### 首次打开被 macOS 拦截

当前应用使用 **ad-hoc 签名，尚未经过 Apple 公证**。如果提示无法验证开发者或 Apple 无法检查恶意软件，请先确认文件来自上方 Release，必要时用附件 `SHA256SUMS.txt` 核对下载文件。

确认来源和文件无误、仍决定试用后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开之后前往“系统设置 → 隐私与安全性”，处理该应用的“仍要打开”提示。不要关闭全局安全检查。如果提示应用已损坏或将损坏电脑，请先停止安装并核对下载文件、反馈具体提示，不要直接套用绕过命令。

## 连接自己的音乐

### 本地音乐

打开“音乐库”，点击“选择文件夹…”添加一个或多个音乐文件夹，再点击“保存目录并扫描”。也可手动填写路径，多个目录各占一行。

扫描后从卡片架打开专辑，点击曲目播放。歌曲从原位置读取，不会复制进仓库或改写音乐标签；移动目录后需要更新路径并重新扫描。根目录直属的单曲分别显示为卡片，子文件夹按含音频的文件夹归并。可读取标签不代表一定能解码播放，**DSF / DFF 暂不支持播放**。

### QQ 音乐

在“音乐库 → QQ 音乐”点击 **QQ 扫码登录**，用自己的手机 QQ 扫码确认，连接后点击 **同步我的曲库**。同步可用的个人歌单与收藏专辑，在线播放受账号和歌曲权限限制。

“读取本机 QQ 曲库”用于导入本机已有的曲库快照，不等于获得在线播放权限，也不是把 QQ 客户端内的加密下载转换为通用音频文件。在线搜索、每日推荐等服务以面板显示的配置与权限状态为准；需要官方 API Key 时，在“高级设置”填写自己的 Key。

若希望下次自动恢复，点击 **保存连接**。连接保存在本机钥匙串；首次保存、读取或更换应用版本时可能需要本人处理系统授权。重新扫码或更换 Key 后，需要再次保存。不保存时仍可使用当前会话；“断开并忘记连接”会移除已保存连接并隐藏 QQ 曲库。

Preview 使用独立身份，不读取或迁移旧 Rhine Music QQ 应用的登录状态。请不要把二维码、Key 或登录信息贴到公开 Issue 中。

### Apple Music

1. 先在系统“音乐”App 中登录自己的账号，并确认资料库已有想听的内容。
2. 打开 Rhine 的“音乐库”，在 Apple Music 区域点击 **允许访问音乐资料库**，按系统提示处理授权，再点击 **同步我的资料库**。
3. 在卡片架或“搜索”中选择 **Apple Music 专辑**或 **Apple Music 歌单**，打开后点播曲目。

专辑只显示已加入自己资料库的曲目，不自动补齐在线目录。可用的发行年份、碟号与曲号会保留；缺失的编号显示为未提供。歌单按原顺序保留条目，同一歌曲出现在不同集合时不会被跨来源合并。

同步结果保存在本机。再次同步会更新专辑与歌单，真正读取或分页失败时保留上次快照；本次未读到歌曲的集合会显示未确认提示。封面依次尝试集合自身、原顺序第一首歌曲的专辑封面，均不可用时显示占位。

Apple Music 使用 MusicKit 原生播放，支持点播、暂停／继续、上一首／下一首、停止及进度调整。是否能播放取决于账号、订阅、地区和曲目可用性。

## 浏览与播放

| 操作 | 用途 |
| --- | --- |
| 卡片架或“搜索” | 按分类浏览，查找专辑、歌曲或歌手 |
| 打开专辑，点击曲目 | 从所选曲目开始播放 |
| 顶部播放／暂停、停止、上一首／下一首 | 控制当前播放队列 |
| 点击顶部正在播放的歌名 | 定位到该条目所属的专辑或歌单，不更换正在播放的内容 |
| “返回专辑架”或 Esc | 退出详情；弹窗打开时先关闭弹窗 |
| 播放与画质设置 | 调整画质、动态效果及当前来源支持的声音选项 |

Rust 负责曲库、后台任务和本地／QQ 播放，Tauri 提供桌面应用封装；界面仍是系统 WebView 与 Three.js。大窗口和较高画质会增加三维渲染负担，可在设置中降低画质；不要把静态截图或某次帧率当作所有设备的表现承诺。

## 已知限制与排查

| 现象或限制 | 当前处理方式 |
| --- | --- |
| Apple Music 应用内音量、切歌淡入淡出不可调 | 当前播放来源不支持这两项；使用输出设备可用的音量控制。部分输出设备本身也可能不支持系统音量滑块。[Issue #41](https://github.com/YingYveltal/Rhine-Music/issues/41) |
| 新收藏的 Apple 内容有名称但暂时没有曲目 | 查看未确认提示，稍后重新同步；如果系统“音乐”中已有歌曲而 Rhine 仍为空，请反馈。有限空结果重读尚未解决全部偶发情况。[Issue #40](https://github.com/YingYveltal/Rhine-Music/issues/40) |
| Apple Music 音乐视频条目 | 可保留在集合中，暂不支持视频播放 |
| Apple 同一队列中的重复歌曲无法点播到指定位置 | 当前不能可靠唯一定位时会明确报错，不静默换成另一条 |
| QQ 或 Apple 某首歌无法播放 | 检查登录、订阅、曲目权限与网络；缓存曲目不代表拥有播放权限 |
| Apple 资料库访问被拒绝或受限 | 按面板提示在系统隐私／使用限制设置中检查授权，再回来重试 |
| 本地文件能看到但不能播放 | 核对文件路径与编码。DSF / DFF 不支持；本版不承诺 DAC 独占、DSD 或无损直出 |

## 数据、升级与反馈

Preview 的曲库索引、封面和配置保存在 `~/Library/Application Support/com.rhine.music.preview/`。QQ 钥匙串服务与 WebKit 存储也使用独立身份。退出再打开会保留 Preview 中添加的曲库和设置，与旧 Rhine Music QQ 并存。

升级前退出正在运行的 Preview，再替换应用；不要删除自己的数据目录。安装包不含歌曲、私人曲库或凭据，原始歌曲仍留在自己的文件夹或由对应平台提供。

在 [本仓库 Issues](https://github.com/YingYveltal/Rhine-Music/issues) 反馈时，附上下载版本、macOS 与芯片型号、所用音乐来源、复现步骤和错误文字即可。公开提交前请隐去账号、二维码、密钥、私人曲库及本机路径。

## 版本与验证范围

`v0.1.0-preview.2` 对应主线 `9cbc751ad01fd8e569e737136506fe4f0ce65516`，构建源码为内容相同的 `a8dc8b68bafa185ca4cd6905f879b5f24a05321a`。应用内部版本仍为 `0.1.0`。本次公开分发使用已验收的同一包，**文档更新不代表安装包重新编译**。

本包完成了开发 Mac 上的资料库同步、专辑点播、暂停／继续、切歌、停止、集合切换和播放中同步检查，以及独立复核。大规模分页、部分收藏、多碟和失败分支主要用合成样本验证；不等同于所有真实曲库、输出设备或主观音质均通过。

Release 附件 `release.json`、`SHA256SUMS.txt` 和 `TRIAL-NOTES.md` 提供对应版本记录。开发者重建与隔离测试见[开发说明](DEVELOPMENT.md)；字体、声音及素材权利范围见 [NOTICE](../NOTICE.md)。
